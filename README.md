# 📚 Biblioteca-Código

Sistema desenvolvido para auxiliar na catalogação e gerenciamento do acervo de uma biblioteca comunitária.

## 📖 Sobre o projeto

O Biblioteca-Código surgiu a partir de uma necessidade real identificada em um grupo sociocultural da minha cidade (@grupocodigo_), que mantém uma biblioteca aberta à comunidade. O objetivo do projeto é facilitar a organização do acervo e tornar mais eficiente o controle dos livros disponíveis.

Além de atender a uma demanda prática, este projeto também representa uma oportunidade de aplicar e aprofundar conhecimentos em desenvolvimento de software, arquitetura de código e boas práticas de programação.

## ✨ Funcionalidades 

* Cadastro de livros
* Cadastro de usuários
* Consulta ao acervo
* Cadastro de livros em lote (Importação de arquivo .xlsx)
* Consulta a status de usuários cadastrados
* Edição e remoção de registros
* Controle de empréstimos
* Busca com filtros
* Relatório com data de empréstimo e data prevista para devolução

*(A lista será atualizada conforme o projeto evoluir.)*

## 🛠️ Tecnologias utilizadas

* **Java** (Linguagem principal)
* **JavaFX & Scene Builder** (Construção de interface rica e responsiva)
* **SQLite** (Banco de dados local leve e integrado)
* **Maven** (Gerenciador de dependências e automação de build)
